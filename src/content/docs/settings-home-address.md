Your home address is the start and end point used by the route planner. If your business operates from a depot, set the depot address here. If you start from home, set that.

## Why it matters

- The first leg of the day starts here.
- The last leg returns here (if "include home return" is on for the day).
- Drive time and total distance are calculated relative to it.

> Each tech can override the org home address with their own on their Personnel profile - useful if multiple techs start from different places.
